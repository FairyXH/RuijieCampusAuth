本版变更
--------
- 修复 00:00-06:00 认证关闭时段失效：原实现只在会话之间的
  daemon 循环里检查窗口，而常驻认证会话（runEAPMD5/runTunnel）在内部
  自行重试且永不返回，导致窗口打开后仍每约 6 秒重试。现在会话内自行
  轮询窗口并返回 KindQuiet，由 daemon 转入 quietLoop 暂停。
- 手动 auth/resume 仍可强制认证，本窗口内不会被自动打断。
- 详见 docs/QUIET_WINDOW_RESIDENT_FIX.md。

功能
----
- 认证器：ruijie-auth 0.11.5，纯用户态，无专属 kmod。
- 静默窗口：00:00-06:00 暂停自动认证（quiet_start=0 / quiet_end=360）。
- 防检测：ruijie-disguise full；UA3F 3.7.0；nftables TTL/MSS/IPID。
- DoH：https-dns-proxy，单实例 5053。
- 代理：OpenClash 0.48.002 + mihomo 1.19.34 softfloat，默认停止。
- 上行：mwan3 校园 WAN → USB 共享 → Wi-Fi STA。
- 统计：nlbwmon + vnstat2。
- 打印：p910nd + LuCI，TCP 9100。
- 穿透：frpc 0.51.3，默认停止。
- USB/IP：usbipd TCP 3240。
- 其他：ZeroTier 1.14.1 + LuCI、Vantage 主题、无线解锁 cfg80211。

注意
----
本固件只适用于 R3G 原版。不要刷到 R3Gv2、R4A 或其他机型。
刷机前备份原厂分区、factory/eeprom 和 Bootloader。
