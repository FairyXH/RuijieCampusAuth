定位
----
「USB 全功能 + R3G 板载 + 插件依赖 + 打印机」的精简固件。
rootfs 53,357,568 字节，UBI 包装后 56,098,816 字节；overlay 首次启动
约 49.5 MiB 可用，可远程 sysupgrade。

认证行为
--------
- 认证成功后不再按定时器主动重认证（reauth_interval=0，
  proactive_reauth=0）；服务器主动发起的重认证仍正常应答。
- 网络断开/被抢占时保留激进抢占重试（preempt=1、retry_interval=3）。
- 00:00-06:00 为校园网认证关闭时段（quiet_window=1，Asia/Shanghai），
  期间暂停自动认证；06:00 自动恢复，手动 auth/resume 可立即覆盖。
- 认证器默认 device=wan，避免 USB 共享把 eth1 当成校园 WAN。
- 外网判定：四台公共 DNS 并发执行真实 DNS 查询（www.baidu.com），
  任一成功即在线；失败后并行 TCP 53 兜底，仍失败再用
  https://www.baidu.com/、https://www.bing.com/、https://www.qq.com/
  二次确认。探测绑定校园网出口。
- 二进制内嵌 time/tzdata，守护进程使用 TZ=Asia/Shanghai；日志和
  quiet window 都按本地时间。

固件内置
--------
认证器：ruijie-auth 0.10.0（纯用户态、无专属 kmod）
        + `log` / `probe --device`、logs2、full 帧伪装
防检测：ruijie-disguise full
        - nftables：TTL=128、TCP MSS=1460、IPID=0（内核改写）
        - UA3F 3.7.0：NFQUEUE 只排队 TCP SYN，改写 TCP timestamp/window
        - UA3F desync reorder=1（1500/8，80/443）；inject=0
DoH：   https-dns-proxy（自定义 AdGuardHome 端点，单实例 5053）
主题：  luci-theme-vantage + luci-app-vantage 1.0.21 + zh-cn
上行：  mwan3，校园 WAN → USB 共享 → Wi-Fi STA
        ICMP 223.5.5.5/119.29.29.29 跟踪，连续 3 次失败切换
        default_rule 使用 use_policy（写成 policy 会让 mwan3_rules
        为空、failover 静默失效）；zz-r3g-defaults 会纠正旧 overlay
防检测范围：ua3f-scope 从锐捷认证器解析校园网接口（支持显式名与
        auto），仅对该出口做 NFQUEUE/改写；desync_reorder 只在该
        接口有地址时开启。其他出口直通，避免 Android/iOS 超时。
DNS：   zz-r3g-defaults 设 filter_aaaa=1，LAN 客户端只拿到 IPv4
Wi-Fi： wpad-mbedtls
QoS：   SQM/CAKE 参数内置但默认关闭（MT7621 上 CAKE 损失约 35-40 Mbit；
        实测关=82M/满载 71-81ms，开=46M/满载 26-33ms）。LuCI 可一键开启。
统计：  nlbwmon（1h 持久化）+ vnstat2（5 分钟保存）
打印：  p910nd + LuCI，TCP 9100，USB 打印机热插拔重启
重启：  watchcat，6 小时无 ping 才重启
穿透：  frpc 0.51.3 + LuCI（预配置，默认停止）
代理：  OpenClash 0.48.002 + mihomo 1.19.34 softfloat（默认停止）
USB/IP：usbipd TCP 3240 + usbip-server/client + usbip-share
UPnP：  miniupnpd-nftables，LAN 侧 secure mode
其他：  luci-app-wol、luci-app-commands、usbutils、usb-modeswitch
kmod：  237 个（USB 全功能、常用文件系统、USB Wi-Fi、串口/网卡/
        音频/视频/HID/打印机、R3G 板载、插件依赖）
